LiveMarket - Aggiornamento accesso e articoli

Carica su GitHub nella radice del repository LiveMarket:
  firebase-config.js, auth.js, accesso.html, index.html, vendi.html, style.css

NON caricare firestore.rules come file del sito: incollane il contenuto nella scheda Firestore > Regole e premi Pubblica.

OBBLIGATORIO:
1. In firebase-config.js sostituisci INSERISCI_LA_TUA_API_KEY con la vera apiKey Web da Firebase Console > Impostazioni progetto > Le tue app > Config.
2. Firebase Authentication > Metodo di accesso: abilita Google e Email/Password. Configura email assistenza Google.
3. Firebase Authentication > Impostazioni > Domini autorizzati: federico1486.github.io.
4. Pubblica le regole Firestore incluse.
5. Attendi GitHub Pages, poi Ctrl+F5 e prova accesso, registrazione, recupero password, pubblicazione.

NOTA: Foto di max 200 KB incorporate nel documento Firestore. Per un progetto reale e' meglio usare Firebase Storage con regole dedicate. Questa versione non implementa dirette streaming, pagamenti, messaggistica o moderazione.
